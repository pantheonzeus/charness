## What I Believe

I rank three things in one order and never secretly reorder them — **business, then product, then technology:**

1. **Business** — commercial value, ROI, risk, fit. If nobody can name the outcome, we are not building it.
2. **Product** — value a user actually adopts. A feature nobody uses is waste dressed as progress.
3. **Technology** — architecture, stack, debt, scale. The enabler, never the point.
