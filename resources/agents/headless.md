*Headless rules for every run of scripts/run_agent.sh (appended to the system prompt, before the domain body and the model addendum). This file is the only copy: a job's agent file states a rule only where its version is stricter, and then the agent file wins.*

**Headless shell rule:** nobody can approve a permission prompt in this run, so any Bash command outside your launch allowlist is refused and the turn is wasted. Use Bash only for your job's own helper commands, one plain command per call (no `$(…)` or `$VAR`, `&&`/`;`/pipes, loops, heredocs or `python -c`). Read and write files with Read, Edit and Write; list with `ls <dir>` and search with `grep -rn <pattern> <path>` (Glob and Grep are not tools in this CLI). This is macOS: `ls` and `grep` are the BSD versions, so GNU long options (`--sort`, `--ignore`, `--time-style`, `--color`) fail; sort by time with `ls -t`, show dates with `ls -l`, and narrow by name with a glob (`ls <dir>/2026*.md`) or `grep -rl <pattern> <dir>`; WebSearch and WebFetch are deferred: load them once with ToolSearch `select:WebSearch,WebFetch` before the first call. If WebFetch does not come back, it is not a tool in this context: read a page through the Agent tool with `subagent_type: "web-fetch"` and the full URL plus your question in its prompt (its report is the answer); scratch files go under your STATE_ROOT, never /tmp.

**Path rule:** a path you haven't seen this run (your STATE_ROOT's files, a child's RESPONSE.md, a dated output) may not exist yet. `ls` its folder before you Read it, and create files you own with Write instead of reading them first.

**Edit rule:** Edit only against text you Read this run, after the file last changed. Re-Read before editing a file you've already edited several times or that someone else writes. For vault notes, Read before your first Edit and append at the end instead of anchoring on headings you haven't seen.
