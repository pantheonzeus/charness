# Business Model Pattern Library — trigger questions

Working list for step 3 of `business-model-design`. Pattern names follow the cited books. Before quoting a pattern definition in a client deliverable, check the wording against the source. This file is a prompt aid, not a citation.

## A. St. Gallen Business Model Navigator — 55 patterns (Gassmann, Frankenberger, Csik)
Grouped here by the trigger question that surfaces them. The grouping is ours, not the book's.

| Trigger question | Patterns |
|---|---|
| Can we charge differently for the same value? | Flat Rate, Freemium, Pay per Use, Pay What You Want, Subscription, Razor and Blade, Add-on, Auction, Hidden Revenue, Robin Hood |
| Can the customer stop owning? | Rent Instead of Buy, Fractional Ownership, Guaranteed Availability, Performance-based Contracting, Solution Provider |
| Can we own the customer relationship longer? | Customer Loyalty, Lock-in, Cross-selling, Experience Selling, Supermarket |
| Can others build or sell for us? | Crowdsourcing, Crowdfunding, Open Source, Open Business Model, User Designed, Franchising, Affiliation, License, White Label, Ingredient Branding, Shop in Shop |
| Can we sit between parties? | Two-sided Market, Peer to Peer, Orchestrator, Layer Player, Integrator, Revenue Sharing |
| Can we exploit an asset or capability elsewhere? | Make More of It, Leverage Customer Data, Trash to Cash, Barter, Cash Machine |
| Can we change the channel or the cost base? | Direct Selling, E-commerce, Digitization, Self-Service, No Frills, From Push to Pull, Long Tail, Mass Customisation |
| Can we serve a radically different segment? | Target the Poor, Reverse Innovation, Ultimate Luxury, Aikido, Reverse Engineering |

Later "55+" editions add patterns for IoT and data. For connected-product cases, check the current card set.

## B. Strategyzer *The Invincible Company* — Invent & Shift patterns
**Invent patterns** (new-to-the-world models):
- *Frontstage disruption:* Market Explorers, Channel Kings, Gravity Creators
- *Backstage disruption:* Resource Castles, Activity Differentiators, Scalers
- *Profit-formula disruption:* Revenue Differentiators, Cost Differentiators, Margin Masters

**Shift patterns** (moving from a worse to a better model):
- *Value proposition:* product → recurring service; low tech → high tech; sales → platform
- *Frontstage:* niche market → mass market; B2B → B2(B2)C; low touch → high touch
- *Backstage:* dedicated resources → multi-usage resources; asset heavy → asset light; closed → open innovation
- *Profit formula:* high cost → low cost; transactional → recurring revenue; conventional → contrarian
