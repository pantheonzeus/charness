# brand/ — the employer's house style for client-facing deliverables

Read by `sales/audience-of-one-report` (and any skill that renders a branded deliverable).

- `palette.json`: `font {family, file, licence}`, `text`, `accent`, `cycle[]` ({name, hex}), `grid`, `fills`, `heatmap[]`, `headings`. Never put a hex value here you have not read from the employer's brand guide.
- `house-style.md`: house-style name, CTA section heading, brand bundled skills, internal knowledge base, reference briefs.
- `fonts/`: the brand font file and its licence.
- `examples/`: reference deliverables modelled on this employer's real ones. They stay in the pack.

No `brand/` (or no active pack): skills fall back to greyscale, a system sans and the heading "How we can help".
